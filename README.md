## What is Maestro Flow?

[Maestro Flow](https://www.uipath.com/product/maestro) is a UiPath platform capability for orchestrating end-to-end business processes that combine multiple types of work, including:

- AI agents
- APIs
- human decisions
- enterprise automation
- document processing
- data workflows
- approvals
- integrations

It helps coordinate automation across people, systems, and agents in a single workflow.

## Why This Repository Exists

Maestro Flow is an emerging ecosystem. As more teams start building with it, there is a growing need for a central place to discover:

- working examples
- reusable patterns
- open-source projects
- tutorials
- integrations
- experiments
- enterprise patterns

This repository exists to make discovery and community collaboration easy — one place where the Maestro Flow community can share, find, and learn from each other's work.

## Project Entry Format

Every project entry follows the same format, so the list stays consistent and easy to scan.

### Project Name

**Description:** Short explanation of what the project does.

**Category:** AI Agents / Human-in-the-Loop / etc.

**Author:** Name or GitHub username

**Links:**
- GitHub
- Demo
- Tutorial

**Technologies:** UiPath Maestro Flow, Agent Builder, IXP, APIs, etc.

**License:** License name if available.

> Use [templates/project-submission-template.md](templates/project-submission-template.md) as the starting point for a new entry.

## Submit Your Project

There are two easy ways to add a project:

### Option 1 — Submit via GitHub Issue

Open the [Submit a Maestro Flow Project](https://github.com/1aifanatic/awesome-maestro-flow/issues/new?template=submit-project.yml) issue form and fill it in. A maintainer will review it and add the project to the list.

### Option 2 — Submit via Pull Request

Fork this repository, add your project entry to the correct category file, and open a pull request. See [CONTRIBUTING.md](CONTRIBUTING.md) for step-by-step instructions.

**You keep ownership of your work.** This repository links to external repositories — contributors are never required to move their code here.

## Submission Requirements

**Required:**

- Project name
- Short description
- Project URL
- Author
- Category
- Technologies used
- License, if applicable

**Strongly recommended:**

- A README in the project repository
- Screenshot or demo
- Setup instructions
- Architecture diagram
- Known limitations

**Not accepted:**

- Spam
- Unrelated projects
- Malicious code
- Pirated material
- Copied work without attribution
- Misleading projects
- Purely promotional pages with no useful Maestro content
