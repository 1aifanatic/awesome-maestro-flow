# Contributing to Awesome Maestro Flow

Thank you for contributing! Awesome Maestro Flow is a community resource, and every project, fix, and improvement makes it more useful for everyone building with UiPath Maestro Flow.

## What You Can Contribute

- Adding projects to the list
- Fixing broken links
- Improving project descriptions
- Suggesting new categories
- Improving documentation
- Reporting outdated information

## Contribution Methods

### Method 1: Submit via GitHub Issue

1. Open the [Submit a Maestro Flow Project](https://github.com/1aifanatic/awesome-maestro-flow/issues/new?template=submit-project.yml) issue form.
2. Fill in the form fields: project name, project URL, description, author, category, technologies, and license.
3. Submit the issue. A maintainer will review your submission and add it to the list.

### Method 2: Submit via Pull Request

1. **Fork** this repository on GitHub.

2. **Create a branch** for your change:

   ```bash
   git checkout -b add/project-name
   ```

3. **Add the project** to the correct category file under `projects/`. Not sure which category fits? Check the [Project Categories](README.md#project-categories) section.

4. **Follow the project format** — each entry should match the structure in [README.md](README.md#project-entry-format) and [templates/project-submission-template.md](templates/project-submission-template.md).

5. **Commit** your change:

   ```bash
   git commit -m "Add Project Name"
   ```

6. **Push** your branch:

   ```bash
   git push origin add/project-name
   ```

7. **Open a pull request.** Automated checks (for example, markdown link validation) will run, and a maintainer will review your change.

## Formatting Standards

Project entries should:

- be concise (a short description, not an essay)
- use neutral, factual descriptions
- avoid exaggerated marketing language
- link directly to the original project
- credit the original author
- identify the license when possible

Example entry:

```markdown
### Project Name

**Description:** Short explanation of what the project does.

**Category:** AI Agents / Human-in-the-Loop / etc.

**Author:** Name or GitHub username

**Links:**
- GitHub
- Demo
- Tutorial

**Technologies:** UiPath Maestro Flow, Agent Builder, IXP, APIs, etc.

**License:** License name if available.
```

## Contributor Behavior

- Be respectful and constructive in all discussions, issues, and pull requests.
- Follow the [Code of Conduct](CODE_OF_CONDUCT.md).
- Do not submit spam, unrelated content, malicious code, or plagiarized material.
- Do not include confidential or proprietary information in submissions.
- Keep changes focused — one project per pull request is preferred.
- If you are fixing a link or a description, mention what you changed in the pull request description.

## Need Help?

If you are not sure how to contribute, open an issue and ask — the community is happy to help.
