# Human-in-the-Loop Projects

A curated collection of Maestro Flow projects involving approvals, reviews, escalations, Action Center, and human decision workflows.

## Projects

### Employee Expense Approval (Part 1)

**Description:** An intelligent multi-tier employee expense approval workflow built with UiPath Maestro Flow, CLI automation, and Claude Code scaffolding. Features auto-approval for expenses under $100, manager approval tasks for $100–$500, and finance escalation for expenses over $500.

**Category:** Human-in-the-Loop

**Author:** Naveen Chatlapalli ([@1aifanatic](https://github.com/1aifanatic))
